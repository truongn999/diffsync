# Superpowers Development Methodology

You have **Superpowers** installed for this workspace.

## Core Rules & Skills

1. **Invoke Skills Proactively**: Check and invoke relevant skills from `.agents/skills/` before taking action.
   - **New Features / Requirements**: Use `brainstorming` before planning or writing code.
   - **Planning**: Use `writing-plans` to produce disciplined, step-by-step plans.
   - **Execution**: Use `executing-plans` or `subagent-driven-development` to execute tasks systematically.
   - **Coding / Changes**: Follow `test-driven-development` (TDD). Write tests first, see them fail, then implement.
   - **Debugging / Failures**: Follow `systematic-debugging` (root cause investigation, minimal reproduction, defense-in-depth).
   - **Verification**: Use `verification-before-completion` before finishing any task or making final claims.
   - **Branch Completion**: Use `finishing-a-development-branch` when wrapping up work.
